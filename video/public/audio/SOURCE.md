# bed.mp3

Generated by `scripts/demo-video/make-bed.mjs 86` (synthesised in code, so no
licence to track), then encoded with Remotion's bundled ffmpeg:

    node scripts/demo-video/make-bed.mjs 86 video/public/audio/bed.wav
    cd video && npx remotion ffmpeg -i public/audio/bed.wav -c:a libmp3lame -b:a 192k public/audio/bed.mp3

Level is set by `loudnorm=I=-23:TP=-2:LRA=7` after render, never by a gain
figure here (see the silent-bed incident in scripts/demo-video).
