Quick log. Or record a single purchase in seconds.

DOCUMENT IMPORT

Upload the paperwork. Review the details. Save your changes.
Upload or paste. Drop files, paste text, or photograph paper. The workspace queues and tracks each one.
Check the document type. Check how the document was identified. Change its type, replace an unreadable file or leave it out.
Check names and units. Review the names, quantities and units read from the document before they are saved.
Suggested exact matches. Only when name and unit are certain and the match is exact. Everything doubtful is one human tap.
Review before saving. Imports live outside your real catalog until you confirm them.
Keep recipe links when importing again. Recipe imports are checked before saving. Importing an updated recipe keeps its existing menu links.
Invoices that check themselves. Compare the invoice total with the sum of its lines. Duplicate invoices are flagged.
Price sheets, row by row. Apply or skip each line. A pack-size change refuses to apply silently. A sheet is an asking price, never a purchase.
Check every imported row. Review possible duplicates and uncertain matches. Imported rows need the same details as manually entered ones.
Spreadsheets with different columns. Check which columns hold names, pack sizes and prices before importing. You can see which columns will be ignored.
Recipe CSVs too. Review the recipe columns before importing. Unreadable rows are shown for you to check.
Word documents. Import text from a Word document without copying it into another file first.
The original stays visible. The photo or PDF sits beside the rows awaiting review while you review. Discard really deletes it.
No duplicate save. Saving the same import twice returns the existing receipt instead of adding duplicate purchases.
Unreadable means unread. Unreadable text stays beside the suggested details so you can correct it against the source.
Match supplier names. Suggested matches can connect a supplier’s “Roma tomatoes” to your “Tomato, Roma” ingredient.
It learns your names. Confirmed supplier names can be remembered for your kitchen’s next import.
Repeat matching without duplicates. Refreshing ingredient matches does not create duplicate ingredient records.
Batch imports tested. Tested with 120-item order guides and 20-invoice batches that stay together.
